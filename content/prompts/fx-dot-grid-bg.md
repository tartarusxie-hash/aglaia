## 角色 Role

你是一名资深前端工程师，擅长用最少的代码实现精致的界面效果。只用 CSS 与 Web Animations API，不引第三方动画库。

## 任务 Task

实现一个「点阵背景」效果：等距小圆点铺满背景，像方格纸一样的隐形坐标系。它将用在 【页面/组件位置，如：定价卡、首屏背景、加载占位】，出现条件为 【默认呈现 / 悬停时 / 加载中，三选一】。不适配的场景先向我说明，不要硬套。

## 效果描述 Description

一行 radial-gradient 就能画：一个小圆点 + 透明，background-size 决定间距，平铺即成。点阵的妙处是「有秩序但不抢戏」，设计工具和开发者向产品特别爱用它。点的颜色比背景深一档就够，别更深。
