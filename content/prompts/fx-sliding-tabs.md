## 角色 Role

你是一名资深前端工程师，擅长用最少的代码实现精致的界面效果。只用 CSS 与 Web Animations API，不引第三方动画库。

## 任务 Task

实现一个「滑动标签页」效果：标签下的一条墨线滑到当前标签，像墨水在流动。它将用在 【页面/组件位置，如：定价卡、首屏背景、加载占位】，出现条件为 【默认呈现 / 悬停时 / 加载中，三选一】。不适配的场景先向我说明，不要硬套。

## 效果描述 Description

墨线是绝对定位的小条，切换时 JS 量一下目标标签的 offsetLeft 和 offsetWidth 写给它，CSS 过渡负责「滑」。字体加载会改变文字宽度，记得在字体就绪和窗口 resize 时重新量一次。用 transform 的版本性能更好，但量位置这件事躲不掉。

## 约束 Constraints

- 动画只用 transform / opacity / filter，不引发布局抖动；
- 尊重 prefers-reduced-motion：用户要求减少动态时改为静态呈现；
- 悬停类效果同时支持键盘聚焦触发；纯装饰层加 aria-hidden；
- 静态默认态必须正确：动效默认静止，悬停才播放（本站页面效果卡片规则）。
